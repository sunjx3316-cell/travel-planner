# 腾讯云公网部署

此部署使用 Docker Compose：`travel-planner` 提供 FastAPI 与静态前端，Caddy 负责 HTTPS、反向代理和证书续期。手机直接访问 HTTPS 域名，无需与电脑同一 Wi-Fi；在 Android Chrome 可安装为 PWA，iPhone 可用 Safari 的“添加到主屏幕”。

## 上线前准备

1. 一台腾讯云 CVM 或轻量应用服务器（推荐 Ubuntu 22.04/24.04，公网 IPv4）。
2. 一个已备案或可解析的域名；添加 `A` 记录到服务器公网 IPv4。
3. 安全组/防火墙放行 TCP `22`、`80`、`443`（不要放行 `8000`）。
4. 服务器已安装 Git 与 Docker Engine / Docker Compose Plugin。

## 首次部署

```bash
git clone https://github.com/sunjx3316-cell/travel-planner.git
cd travel-planner
cp .env.production.example .env.production
nano .env.production
# 填写 DOMAIN、DEEPSEEK_API_KEY（AMAP_KEY 可选）

docker compose up -d --build
docker compose ps
docker compose logs -f --tail=100
```

首次启动会在 `data/` 创建 SQLite 数据库并写入演示数据；该目录作为宿主机挂载，会在容器升级后保留清单、计划、图片与后续采集数据。

## 验证与更新

```bash
curl -I https://你的域名/api/status
git pull --ff-only
docker compose up -d --build
```

证书由 Caddy 自动申请和续期。域名未解析、80/443 未开放，或 DNS 尚未生效时，证书签发会失败。

## 安全提醒

- `.env.production` 含 API Key，只保留在服务器，已在 `.gitignore` 中排除。
- 不要把 `8000` 映射到公网；只能通过 Caddy 的 HTTPS 入口访问。
- 首次上线后建议用腾讯云安全组限制 SSH（22）仅允许自己的固定 IP。
